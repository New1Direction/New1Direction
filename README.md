<summary><b>How this page works</b></summary>
<br>

No JavaScript runs here. GitHub doesn't allow it, so everything is a picture that happens to be alive.

- **The city is data.** A GitHub Action reads each repo's stars once a day and redraws its tower. More stars, more floors. A blinking beacon means the repo changed this month.
- **Every tower is its own picture**, placed edge to edge, which is why you can click them one by one.
- **The motion is CSS inside SVG.** The headline, the shooting stars and the flickering windows are drawn once and animate on their own. If your device asks for less motion, they hold still.
- **The year view is my contribution graph in 3D.** Each day of the last year is a building, taller on busier days. It rises in a wave when the page loads and is redrawn daily.
- **The product shots are real.** The repo.ing and Ohiyo screens are actual screenshots, stored inside each picture and framed in a drawn browser window and phone.
- **Night and day follow your theme.** Switch GitHub between dark and light and the city goes from night to dawn.
- **Lighting a window opens an issue.** An Action reads only your username, adds a lit window and your avatar to the ticker, redraws the city and closes the issue, usually within a minute.
- **The leaves are a vote.** Each one opens an issue too. One vote per person, and the tower in the lead grows a rooftop garden.
- **The game is real.** Four in a row, visitors against visitors. Each arrow opens an issue; an Action checks the move, drops the disc and keeps score. Nobody can move twice in a row.
- **The moon is tonight's moon.** Its phase is worked out from the date. The traffic and the airship are just for fun.
- **"Recently shipped" is real too.** It shows the newest commit on each project, read daily.
- **The weather is the real season.** Snow in winter, petals in spring, fireflies in summer, falling leaves in autumn, and fireworks on New Year's Day and my GitHub anniversary.
- **The project cards update too.** Their star counts are read daily, and the repo.ing fee figure comes from repo.ing's own public badge.

The code is in [`scripts/`](scripts) if you want to build your own.
</details>
